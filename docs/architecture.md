# FieldSignal AI — Architecture

---

## System Overview

FieldSignal AI is a single-page energy intelligence dashboard built on Next.js 16 App Router. It loads a decade of EIA production data at request time on the server, passes it to a client root component, and renders all analytics — KPIs, forecasts, heuristics, scenario projections — synchronously in the browser with no additional network calls (except the optional Claude AI analyst stream).

There is no database. The production data lives in a checked-in JSON file (`data/processed/production_yearly.json`) that is regenerated by a standalone Python ingestion script.

## AI Analyst Request Flow

1. User types a question in `AnalystPanel` and submits.
2. `AnalystPanel` assembles a POST body: `{ question, context: AnalystContext }`.
3. `AnalystContext` is built in `DashboardClient` from the current filter state:
   ```ts
   {
     yearRange: { min, max },
     topOilState: string,
     totalOilLatest: number,        // Kbbl
     yoyOilGrowth: number | null,   // %
     projected2028Oil: number | null,
     statesTracked: number,
     focusedState: string | null,
   }
   ```
4. `api/analyst/route.ts` validates the request, builds a system prompt that instructs Claude to:
   - Answer only from the provided context
   - Distinguish "Data-backed facts" from "Model inference"
   - Flag uncertainty rather than invent numbers
   - Respond in plain language, max 512 tokens
5. The Anthropic SDK streams `text_delta` events; the route proxies them as a `ReadableStream` over HTTP.
6. `AnalystPanel` reads the stream chunk-by-chunk, appending each delta to the last message in state, triggering a re-render each time.

**Important boundary**: Claude receives only the pre-computed context object — not the raw 200+ production records. It cannot access the underlying data directly.

## Forecasting, Insights, Scenario, and Well Economics Logic

| Module | Location | Key Logic |
|---|---|---|
| Historical series | `lib/forecast.ts → buildHistoricalSeries` | Aggregates `filteredData` to one point per year for the selected `kind` (oil / gas) |
| CAGR forecast | `lib/forecast.ts → extendWithForecast` | Fits CAGR over last 5 non-zero points; clamps to [−5%, +20%]; extends to `horizonYear` (default 2030) |
| Quality score | `lib/forecast.ts → extendWithForecast` | `(yearsScore + stabilityScore) / 2`; yearsScore = min(1, n/10); stabilityScore = max(0, 1 − σ/0.30) |
| Heuristic alerts | `lib/insights.ts → generateInsights` | 6 independent checks; sorted by severity; padded to min 3 with monitoring rows |
| Scenario projection | `lib/scenario.ts → runScenario` | Base CAGRs: Downside −2%, Base +2.5%, Upside +5.5%; slider adds ±5 pp; clamped [−10%, +25%] |
| Decline model | `lib/wellEconomics.ts → computeWellEconomics` | Exponential decline, midpoint-of-month convention; monthly cash flow stream; NPV by monthly discounting |
| IRR | `lib/wellEconomics.ts → bisectIRR` | 120-iteration bisection over monthly cash flows; range [−99.99%, +900%]; null if no sign change |
| Breakeven price | `lib/wellEconomics.ts → computeWellEconomics` | Closed-form from NPV = 0: `price = (capex + LOE·Σdf) / Σ(prod·df)` |

## Map Interaction Flow

1. User clicks a state polygon in `MapPanelClient`.
2. `onFocusedStateChange(stateName)` propagates up to `DashboardClient`.
3. `DashboardClient` calls `setFocusedState(stateName)`.
4. A `useEffect` watches `focusedState` and sets `regionA` in `ComparePanel` to the new state.
5. `analystContext` is recomputed (memoized) with the new `focusedState`.
6. `WellEconomicsCalculator` has its own `useEffect` on `focusedState` that loads well parameters from `STATE_PRESETS` — oil price and discount rate are left unchanged.
7. `ActionCenter` re-runs `generateInsights` with the new `focusedState`, enabling state-specific heuristics (outperformance, growth opportunity).
8. Mapbox layer paint properties re-evaluate: focused state gets a 2.5px teal highlight; other states dim to 42% opacity.

## Deployment and Environment Variables

| Variable | Required For | Where Set |
|---|---|---|
| `EIA_API_KEY` | `scripts/fetch_eia.py` (data ingestion only) | `.env.local` or shell |
| `ANTHROPIC_API_KEY` | `app/api/analyst/route.ts` | Server environment / hosting platform |
| `NEXT_PUBLIC_MAPBOX_TOKEN` | `MapPanelClient` (client-side) | `.env.local` (public prefix safe) |

The app runs without `ANTHROPIC_API_KEY` — the analyst panel degrades gracefully.
The map requires `NEXT_PUBLIC_MAPBOX_TOKEN`; without it, the map panel will not render.

**Recommended production setup**: Vercel (or equivalent Node.js host). Set `ANTHROPIC_API_KEY` and `NEXT_PUBLIC_MAPBOX_TOKEN` in the hosting dashboard. `EIA_API_KEY` is only needed to re-run the ingestion script, not at runtime.

## Design Choices and Tradeoffs

### No database
Production data is ~200 rows (10 states × 10 years × 2 types). JSON file on disk is sufficient. A database would add deployment complexity for negligible benefit at this scale.

### Pure HTML/CSS bar charts, no Recharts
Recharts adds ~120 KB to the bundle and introduces its own DOM structure. The production trend and well economics charts are simple enough to render as flex containers with computed heights. This keeps the bundle lean and gives full styling control.

### Inline SVG for cumulative cash flow chart
The cumulative CF chart crosses zero (negative early years, positive after payback). HTML/CSS bar charts cannot represent negative values against a zero baseline naturally. An inline SVG with a dynamically computed `zeroY` coordinate solves this without adding a charting library.

### `ssr: false` for Mapbox
`mapbox-gl` accesses `window` and `document` at import time. Wrapping `MapPanelClient` in `dynamic(() => import(...), { ssr: false })` prevents server-side rendering failures.

### State in `DashboardClient` only
All filter state (year range, focused state, scenario type, CAGR adjustment) lives in one component. This avoids prop-drilling through context providers while keeping the component tree shallow and easy to reason about.

## Reliability and Model Boundaries

| Component | Data Source | Reliability |
|---|---|---|
| KPI numbers | EIA historical data | High — authoritative government dataset |
| Forecast bars | FieldSignal CAGR model | Moderate — simple model; quality score surfaces confidence |
| Scenario projections | FieldSignal scenario model | Indicative only — not EIA projections |
| Action Center alerts | Deterministic heuristics on EIA data | High for data facts; heuristic thresholds are rule-based |
| AI Analyst responses | Claude + AnalystContext | Useful for reasoning; may contain errors; verify before citing |
| Well Economics | Representative basin analogues | Illustrative only — single well, oil only, no royalties/gas |

**The dashboard clearly distinguishes EIA-backed historical numbers from FieldSignal model outputs in every panel, badge, and methodology note.**
